# color_analysis

Color Analysis is a project designed to analyze, process, and visualize color data using Python and Jupyter Notebook. The repository provides tools for extracting color information from images, performing statistical analysis, and visualizing color distributions, making it useful for research, data science, and creative applications.

## Features

- **Color Extraction:** Identify and extract dominant colors from images.
- **Statistical Analysis:** Compute color statistics, histograms, and distributions.
- **Visualization:** Generate visual representations of color data.
- **Jupyter Notebooks:** Interactive exploration and reproducibility.

## Technologies Used

- **Jupyter Notebook** (51.7%)
- **Python** (48.3%)
- Core libraries: `numpy`, `matplotlib`, `scikit-image`, `opencv-python`, and more.

## Getting Started

### Prerequisites

- Python 3.8+
- Jupyter Notebook
- Package manager: pip or conda

### Installation

Clone the repository:

```bash
git clone https://github.com/senghuyjr11/color_analysis.git
cd color_analysis
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### Usage

1. Start Jupyter Notebook:

    ```bash
    jupyter notebook
    ```

2. Open notebooks in the `notebooks/` directory and follow instructions for color analysis tasks.

3. Place your images in the `data/` directory or update paths in the notebooks.
